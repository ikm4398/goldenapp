### Installation

You can install this app using the [bench](https://github.com/frappe/bench) CLI:

```bash
cd $PATH_TO_YOUR_BENCH
bench get-app https://github.com/ikm4398/goldenapp_for_attendance_report.git
bench --site sitename install-app goldenapp
```
